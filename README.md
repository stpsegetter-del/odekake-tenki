# おでかけ天気

出かける前の **これから12時間の雨と気温** が、ひと目でわかる天気アプリです。
スマホのホーム画面に追加すると、ふつうのアプリと同じように 1タップで開けます。

- 料金は **完全に0円** です（APIキーの登録も不要）
- 登録した場所と設定は **この端末の中だけ** に保存されます。外部に送信しません
- インターネットにつながらなくても、前回の予報を表示します

---

## できること

### メイン画面

| 表示 | 内容 |
| --- | --- |
| **雨の警告** | この先まとまった雨が降るときだけ、いちばん上に大きく出ます |
| **いまの天気** | 天気アイコン・気温・体感温度 |
| **これから12時間のグラフ** | 棒＝降水確率、折れ線＝気温。画面幅に12時間ぜんぶ収まります |
| **傘・服装のカード** | 「傘を持って行きましょう」「薄手の上着があると安心」など |
| **雨雲レーダー** | 登録した場所を中心に、過去30分〜この先60分の雨雲の動き |
| **明日の予報** | 3時間ごと |
| **5日間の予報** | 曜日・天気・降水確率・最高/最低気温 |

- グラフの時間を **タップ** すると、その時刻の体感温度・降水量・湿度・風速が見られます。
- グラフ上の **うすい帯** は、設定した「出かける時間帯」です。
- グラフの上のタブで **雨 / 体感 / 風 / 湿度** を切り替えられます。

### 雨雲レーダーについて

- **▶ボタン**で、過去30分 → いま → この先60分 の雨雲が10分きざみで動きます。
- スライダーで手動でも送れます。**「予想」の札**が出ているコマは、これからの予測です。
- **＋ − ボタン**で見る範囲を変えられます（市街地〜地方全体）。
- 赤い印が、登録したあなたの場所です。
- 地図を指でドラッグして動かす作りには**あえてしていません**。
  そうするとページを縦にスクロールできなくなり、かえって使いにくくなるためです。
- 雨雲レーダーは**日本国内のみ**です（気象庁のデータが日本を対象にしているため）。
  海外の場所を選んだときは、その旨を表示して非表示になります。

### 場所

- 場所は何件でも登録できます。画面上部のタブで切り替えます。
- **町名・丁目まで** 指定できます（例：「渋谷区神南」「大阪市北区梅田」）。
- 「自宅」「職場」など、好きな名前を付けられます。

### 設定（右上の歯車）

| 項目 | 説明 |
| --- | --- |
| 場所 | 追加・名前の変更・並び替え・削除 |
| 暑がり・寒がり | 服装アドバイスの基準を 3℃ ずらします |
| 出かける時間帯 | 平日・休日それぞれで設定。**この時間だけを見て** 傘と服装を判断します |
| テーマ | 自動 / ライト / ダーク |
| 雨のアニメーション | 雨のときに雨粒を降らせるかどうか |

> 「出かける時間帯」を設定しておくと、**寝ている間の雨で「傘を持って」と言われる** ことがなくなります。
> このアプリでいちばん効く設定なので、最初に入れておくのがおすすめです。

## スマホで使えるようにする（GitHub Pages・無料）

ここが一番大事なステップです。以下の手順で、誰でも無料で公開してスマホからアクセスできます。

### 1. GitHubアカウントを作る（すでに持っていればスキップ）

<https://github.com/> にアクセスし、無料アカウントを作成します。

### 2. 新しいリポジトリを作る

1. 右上の「＋」→「New repository」をクリック
2. Repository name に `odekake-tenki` などお好きな名前を入力
3. 「**Public**」を選択（Private だと無料枠では Pages が使えない場合があります）
4. 「Create repository」をクリック（README 等は追加しなくてOK）

### 3. ファイルをアップロードする（gitコマンド不要）

1. 作成したリポジトリのページで「uploading an existing file」というリンクをクリック
2. `odekake-tenki` フォルダを**開いて**、その **中身だけ** をドラッグ＆ドロップします

   > **ここが一番まちがえやすいところです。**
   > `odekake-tenki` フォルダ **ごと** 入れてはいけません。フォルダごと入れると
   > `index.html` が1階層深くなり、公開URLのトップが 404 になります。
   > アップロード後、リポジトリのトップに `index.html` が**直接**見えていれば正解です。

   入れるもの（**全17ファイル・フォルダはありません**）：

   | 種類 | ファイル |
   | --- | --- |
   | 画面 | `index.html` `styles.css` |
   | プログラム | `app.js` `chart.js` `sky.js` `radar.js` `advice.js` `weather.js` `geocode.js` `muni.js` `store.js` `icons.js` |
   | PWA設定 | `manifest.json` `sw.js` |
   | アイコン | `icon-192.png` `icon-512.png` `icon-maskable-512.png` |

   `tools` フォルダ（アイコン生成・ローカル確認用）と `README.md` は無くても動きます。

   > **PNGをそのまま入れて大丈夫？** → はい、問題ありません。
   > GitHubは画像をそのまま保存し、Pages もそのまま配信します。
   > このアプリはアイコンを**他のファイルと同じ場所（リポジトリ直下）**に置く設計なので、
   > フォルダを作る必要はありません。

   > **`manifest.json` を入れ忘れないでください。**
   > これが無いと、ホーム画面に追加したときのアプリ名とアイコンが正しく出ません。
   > 拡張子が `.json` のファイルは一覧で埋もれやすいので、最後に確認を。

3. 一番下の「Commit changes」をクリック

### 4. GitHub Pages を有効にする

1. リポジトリの「**Settings**」→ 左メニューの「**Pages**」
2. **Source** を「Deploy from a branch」にする
3. その下の **Branch** を `None` から **`main`**（または `master`）に変え、右のフォルダ欄を **`/ (root)`** にする
4. **「Save」ボタンを押す** ← これを押さないと何も始まりません
5. 1〜2分待って、**ページを再読み込み**すると公開URLが表示されます

### 公開URLが表示されないときは

上から順に確認してください。

| # | 確認すること |
| --- | --- |
| 1 | Branch が `None` のままではないか。`main` に変えて **Save を押したか** |
| 2 | リポジトリが **Public** か（Private だと無料アカウントでは Pages が使えません） |
| 3 | 「**Actions**」タブに `pages build and deployment` があるか。緑チェック＝完了、黄色＝処理中、赤＝失敗。**空なら Pages がまだ有効になっていません** |
| 4 | Settings → Pages のページを **F5 で再読み込み**したか（自動更新されないことがあります） |

URLは決まった形なので、**表示を待たずに直接開いても構いません**。

```
https://＜ユーザー名＞.github.io/＜リポジトリ名＞/
```

ここで **404 が出る場合**は、フォルダごとアップロードしている可能性が高いです。
`https://＜ユーザー名＞.github.io/＜リポジトリ名＞/odekake-tenki/` で開けるなら、それが原因です。
リポジトリの中身を消して、手順3をやり直してください。

### 5. スマホのホーム画面に追加する

公開URLをスマホのブラウザで開いて、

- **iPhone（Safari）**：下の共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：右上のメニュー → 「ホーム画面に追加」／「アプリをインストール」

これでアイコンから 1タップで開けるようになります。

> **位置情報について**：現在地の自動取得は、`https://` で公開されたページ（GitHub Pages はこれに当たります）か
> `localhost` でのみ動きます。ファイルを直接ダブルクリックして開いた場合は使えないので、
> そのときは地名検索で登録してください。

## 判断のしくみ

### 傘

**安全重視**の設定にしてあります。「持って行ったのに降らなかった」より「持たずに濡れた」を避ける考え方です。

| 状態 | 条件 |
| --- | --- |
| しっかりした傘を持って | 降水確率 60%以上、または 合計降水量 3.0mm以上 |
| 傘を持って行きましょう | 降水確率 30%以上、または 合計降水量 1.0mm以上 |
| 折りたたみ傘があると安心 | 降水確率 10%以上 |
| 傘はいりません | 上記以外 |

基準を変えたい場合は `advice.js` の上のほうにある `POP_UMBRELLA` などの数値を変えてください。

### 服装

**体感温度の最低値**で判断します（設定の「寒がり／暑がり」で ±3℃ ずれます）。

| 体感温度 | アドバイス |
| --- | --- |
| 26℃ 以上 | 半袖でだいじょうぶ |
| 21〜26℃ | 長袖1枚でちょうどいい |
| 16〜21℃ | 薄手の上着があると安心 |
| 8〜16℃ | しっかりした上着を |
| 8℃ 未満 | 厚手のコートを |

昼と夜の体感差が 7℃ 以上あるときは、「脱ぎ着しやすい服が便利です」と伝えます。

## データについて（正直な話）

- **予報**：[Open-Meteo](https://open-meteo.com/) を使っています。モデルは指定していません。
  Open-Meteo が地域ごとに最適なモデルを自動で選び、**日本国内では気象庁（JMA）のモデル**が採用されます。
  - 補足：`models=jma_seamless` と明示指定すると **降水確率が一切返ってこない**（すべて `null` になる）ため、
    あえて指定していません。このアプリの主役は降水確率なので、この選択が必要でした。
- **場所の検索**：[国土地理院 住所検索API](https://msearch.gsi.go.jp/) を使っています。
  見つからないときだけ Open-Meteo の地名検索に切り替わります（駅名・海外向けの保険）。
- **現在地の住所**：国土地理院の逆ジオコーダ＋同梱の市区町村コード表（`muni.js`）で割り出しています。
- **雨雲レーダー**：気象庁「高解像度降水ナウキャスト」のタイル画像を使っています。
  下地の地図は国土地理院の淡色地図タイルです。地図ライブラリは使わず、
  タイルを自前で並べているので、追加の読み込みはありません。

### 知っておいてほしい制限

- **降水確率と降水量は、出どころのモデルが違います。** そのため
  「確率は 37% なのに、降水量は 6mm」といった食い違いが起きることがあります。
  アプリでは判断の根拠として**両方**を表示しているので、数字が合わないときは降水量のほうを重く見てください。
- **祝日は判定していません。** 「出かける時間帯」の休日設定は **土曜・日曜のみ** に適用されます。
- 5日間予報のうち、**4〜5日先は「傾向」程度**に見てください。気象モデルの精度が実用になるのは 5日先までです。
- **定時のプッシュ通知はできません。** サーバーを持たない構成のためです。
  代わりに、アプリを開いた瞬間に大きな警告を出しています。

## ファイル構成

```
odekake-tenki/
├── index.html        画面の骨組み
├── styles.css        見た目（空の色・ダークモードもここ）
├── app.js            アプリ本体（画面の制御）
├── chart.js          時間別グラフの描画（SVGを自前で生成）
├── radar.js          雨雲レーダー（地図タイルを自前で並べる）
├── sky.js            背景の空の色と、雨・雪のアニメーション
├── advice.js         傘・服装・警告の判定ロジック
├── weather.js        予報の取得とキャッシュ（Open-Meteo）
├── geocode.js        場所の検索（国土地理院 / GPS）
├── muni.js           市区町村コード表（国土地理院のデータを変換）
├── store.js          設定と地点の保存（localStorage）
├── icons.js          天気アイコンなどのSVG（すべて自作）
├── manifest.json     ホーム画面に追加するための設定
├── sw.js             オフラインで開くための仕組み
├── icon-192.png      アプリアイコン
├── icon-512.png      アプリアイコン
├── icon-maskable-512.png   アプリアイコン（Android用）
└── tools/            アイコン生成・ローカル確認用（公開時は不要）
```

ビルド作業はありません。ファイルを置くだけで動きます。
アイコンも他のファイルと同じ場所に置くので、**フォルダは1つも作りません**。

## 公開したあとにファイルを更新するとき

1. GitHubのリポジトリで「Add file」→「Upload files」から、**変えたファイルだけ**を入れ直します
   （同じ名前で上書きされます）
2. `sw.js` の上のほうにある番号を1つ増やします

   ```js
   const CACHE = 'odekake-tenki-v2';   // → v3, v4 ... と増やす
   ```

   これをしないと、一度開いた端末が**古いファイルを持ち続ける**ことがあります。
3. スマホ側では、ブラウザで一度開き直すと新しい版になります
   （ホーム画面のアイコンから開いている場合は、2回開き直すと確実です）

## プライバシー

- 登録した場所・設定・予報のキャッシュは、すべて **端末のブラウザの中だけ** に保存されます。
- 外部に送信するのは、**予報を取るための緯度経度** と **検索した地名** だけです。
- アクセス解析・広告・トラッキングは一切入っていません。
